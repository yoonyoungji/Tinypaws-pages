TinyPaws 1.4.7

This update refines edge walking around macOS desktop boundaries and cleans up the secure-input ice effect.

  • Characters now follow the usable desktop perimeter consistently around the Dock and menu bar.
  • Improved edge-route alignment across displays with different usable screen areas.
  • Removed the outer glow from the secure-input ice effect for a cleaner character silhouette.

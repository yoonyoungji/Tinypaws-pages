TinyPaws 1.4.6

This update adds a playful secure-input pause effect and improves edge walking alignment.

  • Characters now pause with an icy visual effect while macOS secure password input is active.
  • TinyPaws respects macOS secure input and never inspects password characters to create this effect.
  • Movement and animation resume naturally after secure input ends.
  • Refined edge alignment so visible character pixels remain neatly inside the display.
